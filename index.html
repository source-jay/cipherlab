>_ KNOWLEDGE BASE / 04

CIPHER GUIDE

Understand the ideas behind the algorithms.

⫶
TRANSPOSITION

RAIL FENCE CIPHER

A transposition cipher that rearranges the positions of characters. The message is written diagonally across a set number of rails and then read row by row.

PLAINTEXT → ZIGZAG → ROW READ → CIPHERTEXT

Key

The number of rails controls the zigzag pattern. A minimum of two rails is required.

⇄
SUBSTITUTION

MONOALPHABETIC SUBSTITUTION

A substitution cipher replaces each plaintext letter with another letter according to a fixed alphabet mapping. The same mapping is used throughout the message.

PLAINTEXT → LETTER MAP → CIPHERTEXT

Key

A permutation of the 26 English letters. Every letter must appear exactly once.

SECURITY NOTE

CLASSICAL CIPHERS ARE NOT SECURE BY MODERN STANDARDS

These algorithms are valuable for learning cryptographic concepts, but they should not be used to protect real-world sensitive information. Monoalphabetic substitution is vulnerable to frequency analysis, while Rail Fence preserves the original character frequencies.
